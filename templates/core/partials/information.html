Using your local copy

Keep the server on localhost or a trusted network unless the optional login gate and suitable HTTPS access are configured. When login is disabled, anyone with access can read and edit the shared journal.

News feeds show recent items, not a complete archive. Country figures come from a bundled snapshot.

Map and Journal resume when switching pages. Clicking the active header link returns to its main screen. Journal edits save about every minute; check the Saved indicator before closing the tab. Use Backup for a portable copy of saved research.

# Authentication

World Journal does not currently have user accounts or a login screen.

The app is designed for one person or a small trusted household using one local installation. Everyone who can open it can read, create, change and delete the shared journal, settings and backups.

> **Warning:** Do not expose World Journal to the public internet. Django's administration models do not provide protection for the main app, and adding a superuser does not place the journal behind a login.

Authentication needs to be designed as an application feature before public hosting can be supported. This page is reserved for those instructions when that work is complete.
